## 5. BACKSET、B/S及综合背离：可复现失败

### 5.1 最小函数反例

原函数 `strategy.py:_backset:258-268`：

```text
时点1：cond=[False, False]，n=[1,1] → [False, False]
时点2：追加 cond=True，n=3          → [True, True, True]
```

已经计算的第0、1位置从False变成True。极值/标记的历史落点可以是0，而条件首次成立并可确认回填的是2；不能假设0当时已经知道2的触发。

### 5.2 主样本差异计数

以下“差异单元格”是 `(前缀长度, 历史位置, 列)` 组合数量，同一位置可在多个前缀被重复计数；“不同位置数”才是去重后的bar数。

| 列 | 对完整历史的差异单元格 | 不同历史位置数 | 相邻前缀历史变化次数 |
| --- | ---: | ---: | ---: |
| `INNER_BOTTOM_DIV` | 20 | 17 | 17 |
| `INNER_TOP_DIV` | 3 | 2 | 2 |
| `BOTTOM_DIV` | 20 | 17 | 17 |
| `TOP_DIV` | 3 | 2 | 2 |
| `BUY_B` / `BUY_B_RAW` / `BUY`（每列） | 19 | 16 | 16 |
| `SELL_S` / `SELL_S_RAW` / `SELL`（每列） | 1 | 1 | 1 |
| MACD/KDJ/CCI、金死叉 | 0 | 0 | 0 |
| 两方向面积/线背离 | 0 | 0 | 0 |
| WAVE、MACD_ZIG、JB/JS | 0 | 0 | 0 |

主样本最终有B=4、S=1、JB=20、JS=0。辅助样本提供JS正例及另一方向面积背离正例，不能把主样本JS全False的稳定性当作非空验证。

| 信号 | 历史位置（从0开始）/标签时间 | 当时输出 | 追加下一根后 | 完整320根历史输出 |

这些时点都已有≥150根，不能归因为预热期不发送。对应记录可在 `adjacent_differences.csv` 中按列和bar_index定位。发生变化的是柱内背离继而综合背离，CCI/J/DIF/DEA原历史数值保持不变。

B反例的固定历史指标：DIF≈−2.35076684、DEA≈−2.23474572、CCI≈−208.71215、J≈−1.32855；S反例：DIF≈0.17921567、DEA≈−0.42916463、CCI≈213.77596、J≈100.10854。阈值满足但背离标签消失，说明过滤条件本身不能消除BACKSET重绘。

### 5.4 三类时间必须分开

`signal_timing.csv` 记录了所有曾出现的标签，而非只保留最终仍为True的标签：

- **极值发生时间**：对柱内背离指其MACD极值位置。不是必然的价格最高/最低时间；综合信号可能由多个分支组成，没有唯一极值，不能捏造一个price pivot。
- **首次可见时间**：首次在某前缀输出中看到True。因为 `strategy.py:393、403` 强制末根参与BACKSET，它常在极值当根就暂时可见，但只是候选。
- **首次事件确认极值的时间**：追踪后续真实金叉/死叉以及该次HHVBARS/LLVBARS选中的极值位置，见 `first_cross_confirmation_of_extremum`。它只是该波极值被事件确认的时间，不能自动等同整个复合交易规则的永久确认。
- **历史标注时间**：完整历史计算将True写在哪一根，见 `historical_annotation_time`。
- **样本内最后变更/稳定起点**：事后观察该位置最后改变的前缀；**不可当作实时已知的永久稳定保证**。

实测保留至最终的柱内底背离例：

| MACD极值/完整历史标注时间 | 末根机制下首次可见 | 后续金叉确认该极值 |
| --- | --- | --- |
| 00:45 UTC（index45） | 00:45 UTC | 00:51 UTC（index51） |
| 02:39 UTC（index159） | 02:39 UTC | 02:45 UTC（index165） |

柱内顶背离 index184：03:04 UTC即候选可见，03:10 UTC死叉才确认相应极值。后者是完整历史中的峰值回顾落点，不能将03:10的信息视为03:04已知。

本样本统计出 **55 条“列+位置”标签存在事后修改，0条首次可见时间晚于自身bar**。这不表示没有未来依赖：主要表现是候选后来消失，而不是标签首次出现得晚。完整历史保留下来的极值被后来交叉确认，其筛选含未来信息。

开发初版时间测试曾错误要求“最终标签至少一条首次延迟出现”，在本样本失败。根据实际结果，测试改为完整记录**所有曾出现的候选及撤销过程**，并分别测量首次可见和确认；没有修改策略，也没有放宽9项已复现缺陷的契约。这一方法校正避免把审计推测强行写成事实。

### 5.5 与实时及当前Web的关系

`latest_signal()`只输出当前末根，因此实时可以发送上述后来消失的候选。完整历史B/S图则可能不再显示它们，两者不一致。依赖未来确认的历史极值/背离应标为**回顾性信号**，不能作为当时可交易信号。

现有 `webapp/` 的信号点实际上来自当时打印的日志，**并不重新执行完整策略重算历史标签**。本次“历史图表标注时间”指完整compute序列的理论标注位置，没有运行Web，也未证明既有日志会随之后计算自动重写。必须区分“策略事后重算图”和“实时日志留痕图”。

## 6. 抄底、逃顶与强背离可达性

### 6.1 末端条件的确定矛盾

`strategy.py:359-362、379、390、424-425、509-510`：

```text
strong_bottom ⇒ area_bottom ⇒ cross_gc ⇒ DIF > DEA
BOTTOM_FISHING 又要求 DIF < DEA

strong_top ⇒ area_top ⇒ cross_dc ⇒ DIF < DEA
TOP_ESCAPE 又要求 DIF > DEA
```

严格大于与严格小于不能同根同时成立；DIF=DEA也无法通过严格交叉。CCI、J和正负轴过滤再宽松都无法解除矛盾。

测试分别枚举125组有限DIF/DEA/前一根关系状态（含负、零、正与相等），覆盖能满足“假设强底/强顶门”的组合，再验证末端不等式全部阻断。这里强门取真只是**分支级布尔假设**，没有伪造原compute的强信号，也没有更换原策略输出。有限枚举是佐证，上述逻辑蕴含才是普遍不可能的证明。

### 6.2 新发现：强背离自身的时间/符号错配

在原compute产生一致MACD、首根MACD=0的有限输入下：

- 面积底背离在金叉当根，MACD>0；柱内底背离位于BACKSET选中的绿柱极小值，MACD≤0。`area_bottom & bar_bottom` 不可能在同根成立。
- 面积顶背离在死叉当根，MACD<0；柱内顶背离位于红柱极大值，MACD≥0。`area_top & bar_top` 同样不能在同根成立。

理由：LLVBARS取自上次死叉之后的区间，包含负柱；若尚无死叉，则区间至少包含初始0，极小值不可能为正。HHVBARS对称包含金叉的正柱或初始0，极大值不可能为负。BACKSET上升沿只能落在所选极值区间起点，不能把面积交叉时点变成同一个柱内极值时点。

实际组件覆盖（两种子各320根）：

| 输出 | seed0数量 | seed1数量 |
| --- | ---: | ---: |
| 金叉 / 死叉 | 14 / 14 | 14 / 14 |
| 面积底 / 面积顶 | 1 / 2 | 6 / 0 |
| 柱内底 / 柱内顶 | 0 / 2 | 6 / 1 |
| 强底 / 强顶 | 0 / 0 | 0 / 0 |

因此无法诚实构造“经原完整策略自然触发强底/强顶”的正例：本身不可达。测试已经覆盖其组件为真和假设强门为真的分支级场景，并对主样本所有前缀验证符号分离；**没有用“样本中恰好没有信号”代替数学论证，也没有将布尔假设冒充端到端正例**。

### 6.3 可能的原意，仅供确认

可能希望表达“先出现柱内极值背离，再在后续金叉/死叉确认面积背离”，或者“交叉前的候选”和“交叉后的确认”是不同事件。也可能原公式使用持续状态/REF来关联两时点。仓库没有足够原公式证据，以上均为**待确认假设**，不是可直接实施的修复依据。

**单纯反转DIF/DEA符号不足以修复**：即使末端符号改为同向，强背离组件仍按同根AND互斥。本阶段未反转符号、未调整AND/OR、未修改任何抄底/逃顶规则。

## 7. ZIG语义、零轴与JB/JS影响

对应 `strategy.py:_zig_pivots:270-340`、`compute:501、514-515`。

| 输入（阈值5%） | 原实现结果 | 结论 |
| --- | --- | --- |
| `[100,90,80]` | 无波峰、无波谷 | candidate只更新新高，初始跌势分支不能启动 |
| `[100,110,120]` | index1、2均为峰 | 110之后继续上涨，并无确认反转 |
| `[100,110,100,90,80]` | index2、3、4均为谷 | 下跌过程中每个新低都标谷，旧标记不撤销 |
| `[-0.01,-0.009,0.001]` | index1、2均为峰 | 零轴附近微量变化就会建立上行标记 |
| `[0.01,0.009,-0.001]` | 全无峰谷 | 与反向序列不对称，首先受初始跌势缺陷影响 |
| `[-0.000001,0.000001]` 对比 `[0.999999,1.000001]` | 前者标峰、后者不标 | 增量相同，基准接近0导致百分比含义极不稳定 |

四组固定短序列和两组合成K线的逐前缀比较均未发现历史波形值变化；算法保留每次运行中新极值，不回头删除。因此本次证据支持“追加因果但峰谷语义错误”，**不支持仅凭ZIG名称认定未来函数**。如果输入历史被修订或截断，则是另一种输入变化，不能混为追加前视。

JB/JS实际影响不是理论推测：seed0的MACD连续值在index13/14/15约为 `−1.352090/−1.916879/−2.356589`，index14已BUY_JB=True，下一根继续下降；index45/46/47约为 `2.417171/2.639131/3.136943`，index46已SELL_JS=True，下一根继续上涨。两320根样本中，JB落在严格持续下降内点共19处，JS落在严格持续上涨内点共4处。

这些是原 `compute()` 输出正例，不是只测辅助函数。部分案例早于150根，只证明计算语义，不代表正式发送；JB/JS追加前缀稳定性的测试覆盖全序列，盘中修订也另有≥150根案例。

“MACD百分比阈值合理”的交易含义尚无原公式支持，不能仅通过几组零轴案例决定替代参数。最小建议是先明确它究竟表示运行中新高/新低还是反转确认，再选统一的确认规则与命名。

## 8. 指标因果性、np.roll和未收盘修订

### 8.1 可复用范围

MACD、KDJ、CCI的逐前缀历史数值不变；独立参考计算也通过。金叉/死叉 `_cross_np()` 已显式将首项前值置NaN，其边界测试正常。KDJ通过的是“首个有效RSV作为初值”的现实现口径，**不是以50为初值的其他软件口径**；平价、缺失、复权和数据源质量仍需单独合同与测试。

面积/线背离的前缀一致性只证明本次没有观察到追加未来数据导致历史变化，不证明信号有效性、原通达信等价性或收益。

### 8.2 np.roll边界

`strategy.py:394、404、412、417` 用 `np.roll(x,1)`，最小例 `[False,False,True]` 被滚成 `[True,False,False]`；首行“前一根事件”为True来自最后一根，明显不符合时间顺序。

主样本 `LAG_BOTTOM/LAG_TOP` 各出现14个对完整历史差异单元格，全部是首项边界状态。测试清首项的参考版本与原版本的 `LINE_BOTTOM/LINE_TOP` 在320个前缀上一致。原因包括初始引用没有足够历史、真实交叉出现后BARSLAST状态重置。BA/BB起点也有边界污染，但不能把其所有变化归因于np.roll而忽略BACKSET。

结论：应修边界以消除非法状态；本次**没有证明DIF线背离最终导出值发生前视污染**，此前审计关于其输出影响的风险判断得到这一限定。

### 8.3 当前bar修订

主样本前151根，末根时间均为02:30 UTC，只把末根close下调15，并相应扩展high/low及更新amount，不改任何已完成输入：

| 字段 | 修订前 | 修订后 |
| --- | ---: | ---: |
| close | 77.270539 | 62.270539 |
| MACD | 0.414381 | −1.500149 |
| J | 60.399978 | 11.954842 |
| CCI | 25.488830 | −355.437224 |
| BUY_B | False | True |
| BUY_JB | False | True |

历史已完成位置的MACD/KDJ/CCI和金死叉保持不变，当前末根指标和候选信号改变。这是**相同bar输入修订**，不是固定历史追加未来数据导致基础指标重绘。

原 `latest_signal()` 对两版都返回相同bar_time、不同数值/信号，说明它没有“收盘确认”语义。修订案例的数据行数≥150，不能靠预热门槛阻断。需要由调用者或信号层明确 `is_closed`、候选/确认状态和修订版本，而不能把盘中True当成不可撤销事件。
